# Adversarial Verification — Canonical Session Flow

## Verdict

The flow is structurally sound and unusually disciplined: it correctly collapses everything onto one 4-state FSM (verified against `core/systems/game_state.py` — the `_ALLOWED_TRANSITIONS` frozenset has **no** `ENGAGEMENT→REFLECTIVE` edge, and the flow's `ENGAGEMENT → HUB → REFLECTIVE` routing for The Fall obeys it exactly), one accumulator primitive in three tiers, and one append-only write-back spine that genuinely proves "no dead end" at both altitudes. Default-to-flagging applied throughout.

## Dead ends

The flow is exhaustive on loop closure; I found no *unhandled* terminus. Three residual hazards:

- **Beat-graph unreachability (Stage 5/7/11).** The one place the core law can break: if the write-back spine seeds a beat whose preconditions are unsatisfiable from current state and no connecting beat is carved, you get a *silent* dead end. This is the flow's own #1 open seam and is correctly named — but it is a true latent dead end until the beat-layer `carve_egress` is built. **Fix:** "prove every seeded beat reachable, or carve a connecting beat" must gate every chaining shape.
- **Stage 8 (The Fall) HUB-with-0-HP sequencing.** The Fall routes `ENGAGEMENT → HUB → REFLECTIVE` in two hops (correct per the frozenset). Risk: if the HUB-side `hp_zero` consequence fires on *tick* rather than *on-entry*, a 0-HP player could dwell at HUB (HUB advances only on player action). **Fix:** make the FALLEN grace-phase fire on HUB entry, not on the next `advance_turn`, so there is no dwellable 0-HP HUB frame.
- **Exploration goal-shape has no concrete integer end-state (Stage 11).** Eight shapes resolve on an integer threshold/clock/lock/quorum/drain; **Exploration "drift satisfied"** is not a concrete end-state — it appears to resolve only on budget expiry. **Fix:** define "drift satisfied" as an integer (e.g. N distinct loci cleared, or a drift-vector magnitude threshold) or state explicitly that Exploration is expiry-only — otherwise its "SUCCESS" branch is undefined.

## Prologue gaps

The plan teaches the load-bearing five + Going Without + Cairn-stone by doing, names earned before spoken — solid. Two real gaps, both around mechanics first met *under stress*:
