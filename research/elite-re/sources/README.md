# Sources

Drop your acquired Elite `.ssd` files here. Suggested layout:

```
sources/
├── Elite-BBCMicro-Cassette.ssd      <- acquire from Ian Bell's site
├── Elite-BBCMicro-Disc.ssd          <- optional alternative version
└── ELITE                            <- extracted flat binary (output of beebem-fs)
```

**This directory's contents are gitignored.** Do not commit binaries.

Source: <http://www.iancgbell.clara.net/elite/> (Ian Bell publicly
released the BBC versions).
